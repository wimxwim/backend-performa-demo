GIN pg_trgm = cari trigram (3 huruf) — tidak scan semua baris. LIKE = scan 6.081 baris satu-satu (Seq Scan) — lambat 200x.
Gimana ini kerja tanpa terminal? — klik untuk buka▼

Tanpa Docker, tanpa curl, tanpa psql. Data 250 UMKM ada di browser sebagai const DATA = [...] (JS array). Saat kamu ketik:

  • LIKE (lambat): DATA.filter(d => d.name.toLowerCase().includes(q)) — scan semua 250 baris + delay 1500-2000ms simulasi Seq Scan 5M (2000ms real di DB).
  • GIN pg_trgm (cepat): pecah query jadi trigram 3 huruf (ayam → aya, yam), cek overlap >0.3 — hanya sentuh baris yang mirip, 5-20ms (real GIN 10-50ms).
  • MatView (ringkas): agregat per kelurahan (Bintaro 1931, Petukangan Utara 1689, dst) — instant <5ms, tanpa scan nama.

Waktu diukur pakai performance.now() — real di browser. LIKE sengaja delay via setTimeout 1500-2000ms biar terasa lambatnya. GIN tanpa delay — cepat beneran.
